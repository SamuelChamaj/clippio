STAVEXON – ukážkový firemný web

Ukážkový web pre lokálnu stavebnú a rekonštrukčnú firmu. Projekt ukazuje, ako môže vyzerať jednoduchý, ale profesionálne spracovaný firemný web s podstránkami, jasnou štruktúrou, kontaktným formulárom a základnou SEO prípravou.

Web obsahuje hlavnú stránku, služby, realizácie a kontakt. Je responzívny, pripravený na mobilné zariadenia a postavený tak, aby návštevník rýchlo pochopil ponuku firmy a vedel odoslať dopyt.

  • Responzívny dizajn
  • Samostatné podstránky
  • Služby, realizácie a kontakt
  • Základné SEO nastavenia
  • Sitemap a robots.txt
  • Čisté URL bez .html
