# Saténové ruže Liora – ukážkový e-shop

Toto je ukážkový predajný web vytvorený pre portfólio Clippio. Web prezentuje handmade značku Saténové ruže Liora zo Zlatých Moraviec a slúži ako demonštrácia balíka Predaj / E-shop.

## Čo web obsahuje

- domovskú stránku s hero sekciou, výhodami, odporúčanými produktmi, recenziami a FAQ,
- kolekcie s produktovým katalógom, kategóriami, filtrovaním a zoradením podľa ceny,
- detail produktu s výberom množstva a farby,
- frontend košík cez `localStorage`,
- zmenu množstva, odstránenie produktu a výpočet ceny,
- objednávkový formulár s demo potvrdením,
- galériu produktov,
- kontaktnú stránku s demo formulárom,
- SEO základ, Open Graph tagy, JSON-LD schema, `robots.txt` a `sitemap.xml`,
- responzívny dizajn a mobilné hamburger menu.

## Technológie

- čisté HTML,
- čisté CSS,
- čistý JavaScript,
- bez frameworkov,
- bez backendu,
- bez databázy,
- bez platobnej brány.

## Dôležité obchodné hranice

Košík, výpočet ceny a formuláre sú ukážkové frontend funkcie. Web neobsahuje reálne odosielanie objednávok, platobnú bránu, sklad, fakturáciu ani napojenie na dopravu. Tieto funkcie sa riešia individuálne podľa rozsahu projektu.

## Stránky

- `/`
- `/kolekcie/`

- `/kontakt/`

## Obrázky

Všetky obrázky sú uložené v priečinku `assets/images/` a používajú formát WebP. Použité sú pripravené produktové obrázky, bez placeholderov a bez stock fotiek.

## Nasadenie

Projekt je pripravený na nasadenie cez GitHub Pages. Po nahratí priečinka do repozitára stačí zapnúť Pages pre príslušnú vetvu. V `sitemap.xml` je použitý placeholder `https://example.com/`; pri reálnom nasadení ho treba nahradiť finálnou URL.


## Clippio URL

Ukážka je vložená na adrese `/ukazkovy-eshop-liora/` a slúži ako príklad rozsahu balíka Predaj / e-shop.

Stránky ukážky majú `noindex, follow`, aby fiktívny e-shop nepôsobil vo vyhľadávaní ako reálny obchod.
