# STAVEXON – ukážkový firemný web

STAVEXON je ukážkový firemný web pre lokálnu stavebnú a rekonštrukčnú firmu. Projekt ukazuje, ako môže vyzerať jednoduchý, ale obchodne použiteľný web pre malú slovenskú firmu v hodnote približne 600–700 €.

Firma STAVEXON je fiktívna. Web slúži ako prezentačná ukážka webového balíka s podstránkami, lokálnym SEO, dôveryhodnostnými prvkami a kontaktným systémom pripraveným na reálne nasadenie.

## Stránky

- `index.html` – Domov: úvod, služby, lokálne SEO, proces, FAQ a hlavné CTA
- `sluzby/` – Služby: detailný rozpis služieb, vhodnosť, rozsah a faktory ceny
- `realizacie/` – Realizácie: portfólio štruktúra, typy prác a bloky pred/po
- `kontakt/` – Kontakt: kontaktné údaje, dopytový formulár a návod na kvalitný dopyt

## Funkcie

- responzívny dizajn
- samostatné podstránky
- mobilné menu
- aktívny stav navigácie
- kontaktný formulár pripravený na napojenie
- lokálna SEO sekcia pre Nitru a okolie
- detailnejšia stránka služieb
- sekcia „Čo ovplyvňuje cenu stavebných prác“
- sekcia „Ako pracujeme“
- portfólio štruktúra vrátane blokov pred/po rekonštrukcii
- zjednotený CTA systém
- unikátne SEO title a meta description pre každú stránku
- Open Graph tagy
- `sitemap.xml`
- `robots.txt`
- `favicon.svg`
- `og-image.svg`
- JSON-LD schema.org pre lokálnu stavebnú firmu
- pripravenosť na GitHub Pages
- čisté URL bez `.html` cez priečinkovú štruktúru

## Technológie

- HTML
- CSS
- JavaScript

## Spustenie lokálne

Stačí otvoriť súbor `index.html` v prehliadači. Podstránky sú uložené v priečinkoch `sluzby/`, `realizacie/` a `kontakt/`, aby sa v URL nezobrazovalo `.html`. Web nevyžaduje build proces ani externý framework.

## Pripravenosť pre GitHub Pages

Projekt je pripravený na nahratie do GitHub repozitára a spustenie cez GitHub Pages. Sitemap je nastavená pre URL:

`https://www.clippio.sk/ukazkovy-web-stavexon/`

## Poznámka k formuláru

Formulár je v ukážkovej verzii pripravený ako prezentačné rozloženie polí. Pri reálnom webe sa napojí na e-mail klienta napríklad cez Web3Forms, FormSubmit, Netlify Forms alebo vlastný backend.

## Poznámka k reálnemu nasadeniu

Pri reálnom webe sa doplnia skutočné fotografie, reálne údaje klienta, presné obchodné podmienky, prípadné referencie a technické napojenie formulára. Web nepoužíva nepravdivé recenzie, hodnotenia ani certifikáty.
