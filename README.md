# Clippio static website

This is a framework-free website built with HTML, CSS and JavaScript.

## Structure

- `index.html` — homepage
- `portfolio/`, `kontakt/`, and other named folders — pages with clean URLs
- `assets/css/` — styles
- `assets/js/` — browser interactions
- `assets/images/` — local images and logo
- `data/` — static gallery and notice data

## GitHub Pages

Publish from the repository root using GitHub Pages. Folder-based pages use clean addresses such as `/portfolio/`, without `.html` in the URL.
